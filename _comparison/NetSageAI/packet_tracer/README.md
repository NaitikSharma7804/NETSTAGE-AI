# Cisco Packet Tracer Verified Cases Repository

This directory contains Packet Tracer lab case files (.pkt / .pka) and verified CLI show outputs organized by domain:

- `vlan/`: VLAN assignment, trunking, switchport security cases.
- `gateway/`: Default gateway, duplicate IP, subnet mismatch cases.
- `dhcp/`: DHCP pool, helper-address relay cases.
- `dns/`: DNS resolution, domain lookup cases.
- `routing/`: Static routes, OSPF, EIGRP cases.
- `acl/`: Standard/Extended ACL traffic filtering cases.
- `nat/`: Static NAT, PAT overload cases.
- `wireless/`: WAP SSID, WPA2-PSK security cases.

Networking team members should place verified `.pkt` files and raw show command output logs in these respective subfolders.
