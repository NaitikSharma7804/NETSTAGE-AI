# Wireless Troubleshooting Guidance

Focus on Layer 1 & 2 Wireless Network concepts:
- SSID match between client and WAP
- Security Mode & Pre-Shared Key (WPA2-PSK) exact match
- 2.4GHz / 5GHz Radio Enabled states
- Switchport VLAN assignment for Access Point management & untagged traffic
- WAP DHCP reservation or static management IP
