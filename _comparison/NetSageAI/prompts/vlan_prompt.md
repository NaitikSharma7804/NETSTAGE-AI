# VLAN Troubleshooting Guidance

Focus on Layer 2 switching concepts:
- Access VLAN assignment (`switchport access vlan <id>`)
- Switchport trunking (`switchport mode trunk`, `switchport trunk encapsulation dot1q`)
- Allowed VLAN lists (`switchport trunk allowed vlan`)
- VLAN database creation (`vlan <id>`)
- Native VLAN mismatches
- Port Security status (`show port-security interface`)
